# Review Style Memory

## Purpose

- kosmo PR을 리뷰하거나 기존 리뷰에서 컨벤션을 추출할 때 이 메모를 적용한다.
- 리뷰는 한국어로 작성한다.
- 자동 생성 PR 본문보다 사람이 직접 남긴 review comment, review summary, resolved thread를 더 신뢰한다.
- 이 파일은 리뷰 규칙의 진입점이다. 작업 전에 아래 `memory/review/`에서 현재 review mode에 적용되는 주제 문서를 처음부터 끝까지 읽는다.
