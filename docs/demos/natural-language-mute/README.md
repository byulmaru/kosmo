# 자연어 뮤트 소개 목업 · PROD-1160

이 폴더를 통째로 행사 기기에 복사하고 `index.html`을 브라우저로 엽니다. 화면 JPG 5개와 로고 PNG 1개가 필요하며 서버·빌드·인터넷 연결은 필요하지 않습니다. 이미지만 발표 자료에 넣어도 됩니다.

## 소개하는 동작

> 〈별의 정원〉 결말이나 반전은 보고 싶지 않아요.

위 조건에 해당하는 **글 전체가 타임라인·검색 결과 등에서 보이지 않는 방식**만 소개합니다. 상단의 적용 화면 선택으로 타임라인과 검색을 전환하고, 각 화면에서 설정 → 적용 전 → 적용 후를 비교합니다. 포인터 또는 키보드 Tab·방향키로 선택할 수 있습니다.

| 적용 화면 | 설정          | 적용 전             | 적용 후             |
| --------- | ------------- | ------------------- | ------------------- |
| 타임라인  | `setting.jpg` | `before.jpg`        | `hidden.jpg`        |
| 검색 결과 | `setting.jpg` | `search-before.jpg` | `search-hidden.jpg` |

- **타임라인:** 결말을 공개한 달빛의 글 전체가 빠집니다. 여울의 작화 감상과 모아의 행사 준비 글은 기존 순서대로 올라옵니다.
- **검색:** 검색어 ‘별의 정원’과 최신 탭은 유지하면서 결말 공개 글이 결과에서 빠집니다. 결말을 밝히지 않는 여울의 작화 감상은 남습니다.
- 숨긴 글의 카드·안내 행·빈자리는 남기지 않습니다. 결과 이미지를 크게 열어도 숨긴 글이 다시 표시되지 않습니다.

2026-10-20 사용자 전달: 개발자 확인에 따라 문장 일부 또는 문장 단위 가림은 소개 대상에서 제외합니다. 이전 문장 가림·공개 예시와 이미지, 원본 HTML은 제거했습니다. 이 자료는 글 전체 숨김의 준비된 모의 결과이며 실제 서비스 기능 구현은 아닙니다.

## 기존 UI 재사용

- 타임라인은 기존 `UniversalShell`·`HomeRoute`를 Relay fixture로 렌더링했습니다.
- 설정은 공용 `PageHeader`·`TextField`·`Button`·`BottomTabBar`와 theme token을 합성했습니다.
- 검색은 공용 `SearchToolbar`·`TabList`·`PostListItem`·`UniversalShell`을 합성한 소개용 결과 화면입니다. 현재 Production `SearchScreen`의 글 검색 탭은 준비 상태이므로 이 목업을 실제 글 검색 구현의 완료 증거로 사용하지 않습니다. 검색 API나 route는 변경하지 않습니다.
- 제작용 Storybook은 `apps/app/src/stories/screens/NaturalLanguageMute.stories.tsx`의 `Setting`, `Before`, `HiddenPosts`, `SearchBefore`, `SearchHidden`입니다. 검색의 게시글은 실제 fragment key와 공용 목록 Provider 조합을 사용합니다.
- 화면 이미지는 SUIT/Pretendard를 포함해 캡처되어 행사 기기 폰트 설치에 의존하지 않습니다. `brand-mark.png`는 기존 앱의 Light 로고 자산입니다.

## 이미지 다시 만들기

`pnpm --filter @kosmo/app storybook:dev`에서 위 다섯 Story를 Light·390×844로 열고 로고·폰트·반응 로딩을 확인해 각각 캡처합니다. 가상의 글과 결과 설명·대체 텍스트가 이미지와 일치해야 합니다. 최종 HTML은 캡처된 이미지를 사용하므로 Storybook에 의존하지 않습니다.

## 범위와 확인

작품·인물·글과 뮤트 결과는 준비한 예시입니다. 실제 모델 연동·판별 정확도, 백엔드·운영 데이터·기존 앱 경로·실제 뮤트 정책이나 프로덕션 배포는 포함하지 않습니다.

2026-10-20 Chromium 기반 내장 브라우저에서 390×844의 설정·타임라인 전후·검색 전후를 직접 확인했습니다. 최종 HTML은 1440×1080·390×844에서 포인터·방향키로 두 적용 화면을 전환했고, 이미지 로딩과 가로 넘침 없음을 확인했습니다. 자동 검증은 최신 head의 GitHub CI `Lint`와 `Test (App)`에 인계합니다. 실제 행사 기기·다른 브라우저·인쇄·screen reader·Native·모델 품질은 미검증입니다.
