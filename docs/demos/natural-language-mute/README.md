# 자연어 뮤트 소개 목업 · PROD-1160

`index.html`을 브라우저로 직접 열면 됩니다. 파일 하나만 행사 기기에 복사해도 되며, 서버·빌드·인터넷 연결이 필요하지 않습니다.

1. 보고 싶지 않은 내용을 문장으로 적는 예시를 읽습니다.
2. 문장에 대응하는 가림 조건을 확인합니다.
3. 같은 피드의 적용 전·후를 비교합니다. 결말을 직접 말하는 글만 가리고 작화 감상·일상 글은 유지합니다.

입력란과 적용 버튼을 조작하는 체험 앱이 아니라 준비한 화면으로 설명하는 정적 자료입니다. 작품·인물·글과 가림 결과는 모두 가상이며 실제 서비스 기능, 모델 추론이나 정확도를 나타내지 않습니다.

## 표시 기준

- KOSMO Light semantic color와 typography 역할을 참고한 독립 소개 자료입니다. 앱의 설정·뮤트 정책·경로는 변경하지 않습니다.
- SUIT/Pretendard가 설치된 기기는 해당 폰트를 우선 사용합니다. 외부 폰트를 요청하지 않으며, 미설치 기기에서는 macOS의 Apple SD Gothic Neo, Windows의 맑은 고딕 등 시스템 sans-serif로 표시합니다. 행사 기기에서도 열어 가독성을 확인하세요.
- 넓은 화면은 전·후를 나란히, 768px 미만은 입력→조건→적용 전→적용 후 순서로 표시합니다. 세로 스크롤로 전체 내용을 볼 수 있습니다.

## 확인 범위

2026-10-19 Chromium 기반 내장 브라우저의 1440×1080, 390×844 viewport에서 전체 페이지를 직접 확인했습니다. 한글 표시, 예시·모의 결과 안내, 글의 순서와 유지/가림 관계를 확인했고 두 폭 모두 가로 넘침이 없었습니다. 넓은 화면의 전·후 행 경계도 정렬했습니다.

표준 포맷 검사는 GitHub의 `Lint` workflow가 담당합니다. 로컬 자동 테스트와 실제 행사 기기·다른 브라우저·인쇄 결과는 검증하지 않았습니다. 앱·Native·모델 검증은 이 자료의 범위 밖입니다.
