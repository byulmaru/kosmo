자연어 뮤트

보고 싶지 않은 이야기, 문장으로 말해보세요.

좋아하는 이야기는 그대로. 피하고 싶은 내용은 가려진 피드를 상상해보세요.

소개용 예시 화면
01

보고 싶지 않은 내용을 적어요

예를 들어, 작품을 아직 보지 않았다면

“아직 보지 않은 작품의 결말이나 반전 이야기는 보고 싶지 않아요.”

문장 입력 예시입니다. 이 화면에서 직접 입력하거나 적용하지는 않아요.

02

이런 내용이 가려져요

작품의 결말이나 반전을 직접 알려주는 글

결말을 말하지 않는 작화 감상이나 일상 이야기는 그대로 보여요.

입력 문장의 뜻을 설명하기 위해 준비한 조건 예시예요.

03

같은 피드, 이렇게 달라져요

가상의 글 3개 중 결말을 말하는 글 1개를 가린 예시

적용 전

예시 피드
  1. 달달빛@moon · 예시

    〈별의 정원〉 마지막에 정원사가 미래의 주인공이었다는 반전, 다시 보니 첫 장면부터 힌트가 있었네.

  2. 여여울@yeoul · 예시

    〈별의 정원〉 배경 작화가 정말 예뻐요. 수채화 같은 색감 때문에 큰 화면으로 한 번 더 보고 싶어요.

  3. 모모아@moa · 예시

    내일 코미버스 갈 준비 끝! 가방에 물이랑 보조 배터리 챙겼어요. 부스 구경할 생각에 두근두근.

적용 후

1개 가림 · 모의 결과

  1. 설정한 조건으로 가려진 예시 글

    작품의 결말·반전을 직접 알려주는 내용

  2. 여여울@yeoul · 예시

    〈별의 정원〉 배경 작화가 정말 예뻐요. 수채화 같은 색감 때문에 큰 화면으로 한 번 더 보고 싶어요.

  3. 모모아@moa · 예시

    내일 코미버스 갈 준비 끝! 가방에 물이랑 보조 배터리 챙겼어요. 부스 구경할 생각에 두근두근.

같은 작품 이야기라도, 결말을 말하지 않는 감상은 그대로 남는 모습을 보여주는 예시예요.
