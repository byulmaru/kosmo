01 · 타임라인에서 글 전체 숨김

결말을 담은 글이 목록에서 빠져요. 남은 글은 기존 순서대로 이어져요.

02 · 검색 결과에서도 글 전체 숨김

같은 조건이 검색 결과에도 적용돼요. 작품을 검색해도 결말을 담은 글은 보이지 않아요.

기존 코스모 UI로 구성한 소개용 목업입니다. 타임라인·검색 결과는 준비한 예시이며 실제 서비스의 적용 결과가 아닙니다.

작품·인물·글은 모두 가상입니다.
실제 모델 판단과 정확도는 검증하지 않았습니다.
