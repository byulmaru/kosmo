# 공개 콘텐츠 방문자 온보딩 정책

## 목적과 권위

PROD-836은 PROD-681의 공개 Profile·Post 진입 경험을 소유한다. 이 정책은 두 이슈와 2026-10-14·2026-10-16 안내 구성과 2026-10-19 범위 조정과 2026-10-20 직접 인증 진입 결정을 반영한다. 시각 배치는 `docs/design/public-content-onboarding.md`가 소유한다.

## 공개 조회와 인증 상태

- 비로그인 방문자는 기존에 조회할 수 있던 공개 Profile·Post를 계속 읽고 탐색할 수 있다. 가입 안내는 콘텐츠를 가리거나 추가 조회 제한을 만들지 않는다.
- 인증 상태는 서버가 반환한 현재 Session으로 판단한다. credential 존재만으로 인증됐다고 보거나 조회 실패를 비로그인 상태로 취급하지 않는다.
- 유효한 Session이 있지만 선택 Profile이 없는 사용자는 비로그인 방문자와 구분한다. 기존 Profile 준비 흐름을 유지한다.
- Account는 로그인과 Membership의 기준이고 Profile은 소셜 행동의 주체다. 안내는 이 차이와 지금 가능한 공개 조회를 설명한다.

## 비로그인 공개 화면

- 공개 Profile·Post의 보호 navigation 메뉴와 로그아웃, 직접 Profile 생성 진입점은 표시하지 않는다. 계정 안내와 별도의 `가입하기`·`로그인` 버튼을 제공한다. 두 버튼 모두 `/login`에서 바로 기존 인증을 시작하며 홈(`/`)을 거치지 않는다.
- full·compact·mobile을 포함한 모든 Web 폭에 닫을 수 있는 하단 CTA를 제공한다. full Web 우측 레일에는 `가입하기`·`로그인` 버튼을 중복 표시하지 않는다.
- 하단 안내는 `/login`에서 바로 기존 인증을 시작하는 `KOSMO에서 계속하기` 버튼과 그 아래의 `팀 별마루 소개`·`개인정보처리방침` 링크로 구성한다. `팀 별마루 소개`는 `https://byulmaru.co/about-us`, `개인정보처리방침`은 기존 공개 `/privacy`로 연결한다.
- 가입·로그인 안내의 하단 CTA는 사용자가 닫을 수 있다. 닫힘은 현재 브라우저 탭에서 탐색하는 동안 유지한다.
- 비로그인 모바일 Web 공개 Profile·Post에서는 헤더 왼쪽 햄버거 버튼으로 좌측 drawer를 열 수 있다. 이 헤더에 별도의 뒤로가기나 오른쪽 메뉴 버튼을 추가하지 않는다. 하단 CTA를 닫은 뒤에도 이 진입을 유지한다.
- 참여 action의 기존 권한은 바꾸지 않는다. 인증이 필요한 행동은 로그인 필요성을 안내하며, 인증 전에 행동을 수행하지 않는다.

## 인증 진입

가입·로그인은 기존 인증 흐름을 사용한다. 인증 과정의 Session 검증과 이전 Profile 상태 초기화, 선택 Profile이 없는 인증 사용자의 기존 준비 흐름을 유지한다. 인증 전에 시도한 참여 행동을 자동 실행하지 않는다.

## 범위

Web의 공개 Profile·Post 방문자 안내와 가입·로그인 진입에 적용한다. Native 앱의 비로그인 공개 화면이나 이를 위한 뒤로가기 버튼은 새로 만들지 않는다. Native 온보딩, 다른 공개 하위 화면의 신규 안내, 인증 수단 추가, 공개 범위 변경과 자동 참여 실행은 포함하지 않는다. 전체 온보딩의 핵심 기능 학습과 통합 검증은 PROD-681이 소유한다.
