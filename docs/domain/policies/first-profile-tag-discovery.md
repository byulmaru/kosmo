# 첫 Profile 태그 기반 사람 찾기

## 목적과 근거

[PROD-1147](https://linear.app/byulmaru/issue/PROD-1147)은 첫 코스모 Profile에 저장한 태그를 사람 찾기와 개별 팔로우로 연결한다. 2026-10-23 사용자 선택에 따라 신규 가입과 기존 별마루 계정 로그인 모두, 첫 코스모 Profile을 준비한 사용자를 대상으로 한다.

첫 Profile 준비는 PROD-1146과 그 첫 Profile 온보딩 정책을 따른다. PR #1254의 2026-10-22 robin-maki 리뷰에 따라 첫 핸들 단계에서 Profile을 생성·선택하고 이후 선택 정보는 단계별로 저장한다. 이 문서는 그 저장 방식을 바꾸지 않는다.

## 진입과 완료

- 진행 중인 첫 Profile 입력을 마친 뒤, 생성·선택한 Profile에 실제 저장된 태그가 있으면 홈의 핵심 기능 안내보다 먼저 해당 태그의 사람 찾기로 연결한다.
- `다음`으로 저장한 태그만 사용한다. `나중에 설정`, 선택 단계 생략과 완료는 미저장 초안을 저장하지 않으며 이미 저장한 태그를 지우지 않는다. 어떤 완료 버튼을 눌렀는지로 별도의 사람 찾기 분기를 만들지 않고 실제 저장된 태그를 기준으로 한다.
- 태그가 없으면 사람 찾기를 생략하고 최종 완료 화면으로 진행한다. 태그 조회 실패를 태그 없음으로 표시하지 않으며 다시 시도하거나 지금은 넘어갈 수 있게 한다.
- 관련 Profile이 없거나 아무도 팔로우하지 않아도 최종 완료 화면으로 진행할 수 있다. 태그 선택·다음 이동·완료 자체는 팔로우를 실행하지 않는다.
- 첫 Profile 흐름을 떠난 뒤 재진입하거나 재로그인한 Profile 보유자에게 첫 온보딩을 다시 시작시키지 않는다. 기존 일반 사용 흐름을 유지한다.

- 사람 찾기 뒤 최종 완료 화면에서만 `시작하기`로 앱에 진입한다. 사람 찾기의 `계속하기`는 최종 완료 화면으로 이동하며, `시작하기` 이후에 사람 찾기를 다시 표시하지 않는다.

## 태그와 관련 Profile

- Profile에 저장된 canonical Hashtag identity로 해당 태그의 관련 Profile을 조회한다. 미저장 입력, 표시 이름을 임의로 재해석한 검색 결과나 추천 목록으로 바꾸지 않는다.
- 여러 태그가 있으면 각 태그의 목록을 선택해서 볼 수 있다. 태그의 저장 순서·개수 제한이나 추천·관련도 순위를 새로 만들지 않는다.
- 인증, 공개 Profile 조건, 차단, 뮤트와 페이지 조회 정책은 기존 [Hashtag 탐색 계약](../decisions/0021-hashtag-related-profile-navigation.md)을 따른다. 본인 Profile에 대한 새로운 후보 제외 정책도 추가하지 않는다.
- 로딩·오류 중에도 태그 맥락과 선택 상태를 유지한다. 이미 확인한 목록을 지우지 않고 실패한 조회만 다시 시도할 수 있게 한다. 다른 태그의 목록을 현재 태그의 결과로 표시하지 않는다.

## 팔로우와 상태

- 팔로우는 사용자가 각 Profile의 action을 직접 실행한 경우에만 요청한다. [Follow Relationship](../objects/follow-relationship.md)과 [Follow Request](../objects/follow-request.md)의 자격·승인 정책을 그대로 적용한다.
- 성립한 팔로우와 승인 대기 요청을 구분한다. 승인 대기 요청을 팔로우 완료나 성립된 관계의 접근 권한으로 취급하지 않는다.
- 같은 활동 Profile로 여러 태그를 탐색해도 동일한 대상 Profile의 팔로잉·요청 중 상태는 일관되게 보인다. 실패를 완료로 표시하지 않고 재시도할 수 있게 한다.
- 사람 찾기에서는 목록 조회와 팔로우·팔로우 해제·요청 취소를 순차 처리한다. 태그의 최초 조회 중에는 태그를 전환하지 않으며, 다음 페이지 조회 중에는 기존 목록을 유지하고 태그 전환·관계 변경을 잠시 제한한다. 관계 변경 중에는 태그 전환과 새 목록·다음 페이지 조회를 시작하지 않는다. 성공·실패 후에는 다시 사용할 수 있고, 조회·관계 변경 중에도 `계속하기`로 진행할 수 있다.
- 성립한 팔로우는 기존 홈 조회에 반영한다. 홈의 콘텐츠 공개·차단·뮤트 정책을 우회하거나 대상의 모든 글이 보인다고 보장하지 않는다.
- 인증 또는 활동 Profile이 바뀌면 이전 활동 Profile의 요청·상태를 새 활동 Profile에 적용하지 않는다.

## 범위와 책임

첫 Profile 입력·생성은 PROD-1146, 홈·핵심 기능 안내는 PROD-1148, 앱 마지막 알림 선택은 PROD-1149가 소유한다. PROD-1147은 저장 태그 기반 사람 찾기와 후속 흐름으로 나가는 연결을 소유하고, 전체 단계 통합은 PROD-681이 담당한다.

[공개 콘텐츠 방문자 정책](./public-content-onboarding.md)에 따라 공개 읽기와 기존 인증 진입을 유지한다. 출발 콘텐츠 위치 전달·자동 복귀와 인증 전 참여 행동의 자동 실행은 추가하지 않는다. 기존 사용자용 태그 추가·검색 진입점, 추천·랭킹·동의어 통합·일괄 팔로우·새 검색 문법도 제외한다.

사람 찾기는 부모 온보딩과 같이 앞으로 진행하며 이전 화면 action을 제공하지 않는다. 브라우저·시스템 뒤로가기를 별도로 막거나 복귀시키지 않는다.
