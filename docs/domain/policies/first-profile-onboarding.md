# 첫 Profile 온보딩 정책

## 목적과 권위

[PROD-1146](https://linear.app/byulmaru/issue/PROD-1146)은 인증을 마친 뒤 Profile이 없는 사람이 첫 소셜
정체성을 준비하는 경험을 소유한다. 이 문서는 2026-10-22 사용자가 검토한 다섯 화면과 생성 후 되돌아가기
선택을 반영한다. 화면 구성과 한국어 문구는 [첫 프로필 온보딩 디자인](../../design/first-profile-onboarding.md)이
소유한다. Profile 생성·편집 자격과 값 검증은 [Profile](../objects/profile.md)의 기존 계약을 따른다.

## 대상과 진입

- 유효한 인증 상태에서 코스모 Profile이 0개인 사람에게 제공한다. 별마루 ID 신규 가입과 기존 계정 로그인을
  구분해 일부를 제외하지 않는다.
- 현재 인증 상태와 Profile 보유 여부를 확인하지 못한 동안에는 입력 화면을 확정하지 않는다. 조회 실패를
  비로그인 또는 Profile 0개로 간주하지 않는다.
- 이미 Profile이 있는 사람의 일반 진입은 기존 선택·사용 흐름을 유지한다. 다만 같은 첫 Profile 온보딩에서
  생성에 성공한 사람이 뒤로 돌아왔을 때는 생성한 Profile을 수정하는 같은 흐름으로 계속한다.

## 입력과 이동

- 핸들, 사진·표시 이름·소개, Profile Tag, 게시 설정, 확인 순서로 진행한다. 기존 프로필 수정 화면 전체를
  가입 온보딩으로 전용하지 않는다.
- 핸들은 필수다. 빈 값, 잘못된 형식, 예약 식별자와 이미 사용 중인 핸들로 완료할 수 없다. 기존 Local handle
  검증과 서버의 최종 유일성 판정을 유지한다.
- 사진·헤더 이미지·표시 이름·소개·Profile Tag는 선택 사항이다. 표시 이름을 입력하지 않으면 핸들을 사용한다.
  소개는 빈 값으로, 사진과 Tag는 관계 없이 시작할 수 있다.
- 게시 설정의 초기값은 기본 공개 범위 Unlisted와 Follow Approval Policy Open이다. 사용자가 바꾼 값은
  온보딩에서 이동하거나 되돌아와도 보존한다.
- 다음과 이전 이동만으로 Profile을 만들거나 수정하지 않는다. 같은 흐름 안에서 입력, 추가·제거한 Tag,
  이미지 선택과 게시 설정을 유지한다.
- 선택 단계의 `지금은 건너뛰기`는 현재 단계에서 다음 단계로 이동한다. 이미 입력한 값을 지우거나 기존
  Profile의 저장값을 초기화하지 않는다.
- 첫 핸들 화면에는 단계를 건너뛰는 action을 두지 않는다. 핸들을 유효하게 입력한 뒤 `바로 시작`으로 나머지
  선택 단계를 생략하고 완료할 수 있다. 두 번째 화면을 거쳐야 하는 추가 조건을 만들지 않는다.
- `바로 시작`은 나머지 단계를 생략하는 명시적 완료 action이다. 이미 입력한 선택 정보는 함께 반영하고,
  입력하지 않은 값은 위 기본값으로 시작한다. 잘못 입력된 선택 정보나 준비되지 않은 이미지를 무시하고
  저장 성공으로 처리하지 않는다.
- `프로필은 나중에 만들기`처럼 Profile을 0개로 남기는 전체 온보딩 스킵은 이번 흐름에 제공하지 않는다.
  공개 콘텐츠의 기존 읽기 권한은 별도로 유지한다.

## 생성과 생성 후 수정

- 처음 `바로 시작` 또는 최종 생성 action을 실행해 성공하면 첫 Local Profile 하나와 Owner Membership을
  준비하고, 생성한 Profile을 현재 활동 Profile로 선택한다. 다른 단계 이동이나 안내 닫기는 생성 action이 아니다.
- 생성에 성공한 뒤에도 이전 입력 단계로 돌아갈 수 있다. 완료 직후의 뒤로가기는 완료 action을 누른 단계로
  돌아가며, 이후에는 이전 입력 단계를 순서대로 볼 수 있다. 핸들 화면에서 바로 완료한 경우에도 이 복귀가 가능하다.
- 되돌아오더라도 생성한 Profile과 그 식별자는 유지한다. 생성 전의 Profile 0개 상태로 되돌리거나 새 Profile을
  추가로 만들지 않는다. Profile이 존재한다는 이유로 같은 흐름의 수정 화면을 곧바로 닫지 않는다.
- 생성 후 수정은 같은 Profile의 사진·헤더 이미지·표시 이름·소개·Tag·게시 설정에 적용한다. Profile 편집과
  기본 공개 범위 변경의 기존 자격을 다시 확인한다. 다른 Profile로 대상이 바뀌면 이전 대상의 입력이나 늦은
  저장 결과를 새 대상에 적용하지 않는다.
- 핸들 변경은 기존 PROD-1146의 제외 범위를 유지한다. 생성 후 핸들 단계로 돌아갈 수 있지만 저장된 핸들은
  확인만 할 수 있다. 나머지 단계는 계속 수정할 수 있다.
- 생성 후 다시 완료하면 해당 Profile을 수정한다. 변경이 없으면 새 생성이나 불필요한 저장 없이 기존 결과를
  유지한다. 생성 후 입력 화면으로 돌아가는 것 자체가 이미 저장한 값을 취소하거나 삭제하지 않는다.
- 직접 가입에서 준비한 Profile과 Tag는 후속 온보딩이 사용할 수 있다. 이 흐름이 사람 추천, 팔로우 또는
  후속 Coachmark를 자동 실행하지는 않는다.

## 검증과 실패

- 핸들, 표시 이름, 소개, Tag와 이미지의 기존 검증을 적용한다. 선택 항목이라는 이유로 입력된 잘못된 값을
  조용히 버리지 않는다.
- 생성·수정 중에는 같은 완료 요청을 중복 실행하지 않는다. 처리 중 입력과 이동은 중복 저장이나 대상 혼동을
  만들지 않게 보호하고, 실패 후에는 입력을 유지한 채 재시도할 수 있어야 한다.
- 생성 성공과 추가 정보 저장 결과를 구분한다. 생성은 성공했지만 나머지 저장이나 선택이 실패한 경우에도
  생성한 Profile을 보존하고 같은 Profile로 남은 처리를 재시도한다. 전체 생성을 다시 실행하지 않는다.
- 생성·수정·선택을 확인하지 못했으면 완료로 안내하지 않는다. 오류는 관련 항목 또는 완료 action 가까이
  표시하며, 서버가 반환한 현재 상태를 기준으로 복구한다.
- 같은 흐름에서 이동하고 되돌아갈 때의 보존을 보장한다. 세션이나 기기를 넘는 장기 초안 저장, 재로그인 뒤
  온보딩 전체 재개는 새 요구사항으로 추가하지 않는다.

## 범위와 관계

- [공개 콘텐츠 방문자 온보딩](./public-content-onboarding.md)과 PROD-836의 공개 읽기·인증 진입은 유지한다.
  공개 콘텐츠에서 시작한 인증 뒤 원래 콘텐츠로 자동 복귀하는 기능은 이번 범위에 넣지 않는다.
- 기존 프로필 편집·설정·추가 생성·전환과 핸들 변경을 재설계하지 않는다. 첫 Profile 온보딩의 입력 경험만
  기존 계약을 활용한다.
- 공용 Coachmark는 PROD-678, 생성 이후 사람 찾기는 PROD-1147, 홈과 핵심 기능 안내는 PROD-1148,
  모바일 마지막 알림 단계는 PROD-1149가 소유한다. 이 문서는 해당 후속 경험의 동작을 추가하지 않는다.
- 게시물 해시태그·해시태그 목록, 추천 Tag·인물·관심사, 인증 수단 추가와 공개 범위 정책 변경은 포함하지 않는다.

## 완료 결과

1. Profile이 없던 Account가 인증 후 필수 핸들과 선택 정보를 입력해 첫 Profile을 생성·선택할 수 있다.
2. 유효한 핸들만 입력한 첫 화면에서도 한 번의 `바로 시작`으로 완료할 수 있다.
3. 각 선택 단계를 생략하거나 되돌아가도 입력한 값과 설정이 유지된다.
4. 생성 후에도 완료 action을 누른 단계로 돌아가 같은 Profile의 선택 정보를 수정할 수 있다. 이 과정을
   반복해도 Profile 수와 식별자는 변하지 않는다.
5. 검증·이미지 처리·생성·수정·선택 실패 후 입력과 이미 생성된 Profile을 보존해 복구할 수 있다.
6. 기존 Profile 편집·선택과 공개 콘텐츠 읽기를 유지한다.
