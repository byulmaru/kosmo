# ADR 0032: Native 초기 로딩 중 잠금·복귀 복구

## 상태

Accepted

## 날짜

2026-10-22

## 맥락

앱 초기 로딩 중 화면을 잠갔다가 돌아오면 일시적인 연결 끊김 뒤 앱 전체나 홈의 오류 화면에 머무를 수 있다.
화면 잠금·복귀는 로그아웃이나 프로필 선택 해제의 근거가 아니다.

## 결정

- iOS와 Android Native 앱은 초기 로딩 중 잠금·복귀와 관련해 중단된 조회를 복귀 후 자동으로 한 번 재시도한다.
  복구되면 사용자는 초기 로딩을 마치고 앱 이용을 이어갈 수 있어야 한다.
- 자동 재시도도 실패하면 기존 오류 안내와 수동 재시도를 제공한다. 연결이 돌아올 때까지 자동 시도를 반복하지 않는다.
- 일시적인 연결 실패만으로 유효한 Session credential이나 클라이언트가 기억하는 selected Profile을 제거하지 않는다.
  먼저 시작한 조회의 늦은 결과가 더 최근의 Account나 Profile 선택을 덮어쓰지 않도록 한다.
- 해당 조회를 복구하는 동안 무관한 화면·내비게이션·다른 Profile의 데이터를 초기화하지 않는다.
  서버가 확인한 인증 만료·guest 전환과 기존 앱 전체 오류의 수동 복구는 각자의 기존 계약을 따른다.

## 이유

잠금 해제 뒤 일시적인 중단에서는 이용을 이어가되, 지속적인 오프라인·서버 오류에서는 오류를 숨기거나 자동
시도를 반복하지 않고 사용자가 다시 시도할 수 있게 하기 위한 결정이다.

## 범위

이 결정은 앱 시작 직후 초기 조회의 잠금·복귀 복구에 적용한다. Web, 정상 로딩 뒤의 일반적인 데이터 갱신,
사용자 변경 작업의 자동 재실행, 기기 재부팅·프로세스 종료 후 복원은 범위에 포함하지 않는다.
iOS와 Android의 잠금·복귀 결과는 각각 검증하며, 한 플랫폼의 비재현을 전체 플랫폼의 영향 없음으로 해석하지 않는다.
