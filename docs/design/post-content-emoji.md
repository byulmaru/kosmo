# Post Content Emoji

원격 본문 커스텀 이모지의 지원 범위와 원격 자산 정책은 [Post Content](../domain/objects/post-content.md)의
원격 본문 커스텀 이모지 계약을 따른다.

## 표시 상태

- 로딩 중에는 원래 shortcode 텍스트를 표시한다. 이미지가 준비되지 않은 빈 공간이나 spinner로 대체하지 않는다.
- 로드에 성공한 이모지는 원래 본문 위치에서 본문 글자 크기에 맞춰 표시한다. 원본 비율을 보존하고 주변 글자의 줄 흐름을 유지한다.
- URL이 없거나 지원하지 않는 표현, 이미지 로드 실패는 텍스트로 남긴다. 별도 오류 toast나 재시도 버튼은 표시하지 않는다.
- 같은 이름이라도 본문에 연결된 이미지가 다르면 각각 표시하며, 한 이모지의 실패로 다른 이모지나 본문을 숨기지 않는다.

## 접근성과 기존 본문 동작

이미지를 표시할 때도 shortcode를 대체 텍스트로 제공하고 이미지와 숨긴 텍스트를 중복 낭독하지 않게 한다.
이모지는 별도 버튼이나 이미지 뷰어 진입점이 아니다. 주변 링크와 본문 navigation, 문단·줄바꿈을 유지한다.
CW 공개 전에는 이모지도 표시하거나 로드하지 않고, 공개 이후 동일한 loading/success/error 표현을 따른다.

## 검증

로딩 지연·성공·실패, 이모지만 있는 본문, 서로 다른 URL의 동명 이모지, 긴 본문과 좁은 폭, 링크 안 이모지,
CW 공개·다시 가리기와 접근성 이름을 확인한다. Web 검증과 Native inline 배치·접근성 검증은 구분해 기록한다.
