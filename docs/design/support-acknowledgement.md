# AI·SW마에스트로 지원 표기

2026년도 AI·SW마에스트로 성과물의 대외 표기를 위해 아래 국문 문구를 원문 그대로 표시한다.

> 이 성과는 2026년도 과학기술정보통신부의 재원으로 정보통신기획평가원의 지원을 받아 수행된 결과물임 (IITP-2026-AI·SW마에스트로)

- Web 오른쪽 레일의 개인정보 처리방침 링크 아래에 표시한다.
  고정 320px 레일에서는 `정보통신기획평가원의` 앞에서 줄바꿈한다.
- Web·Android·iOS 비로그인 메인 화면의 개인정보 처리방침 링크 바로 아래에 표시한다.
- `UI/Copy/S`(12px/130%)와 기존 `foregroundDisabled` 색상 토큰을 사용한다. 두 표시 위치에
  동일한 연한 색상을 적용하며 별도 불투명도 조절은 하지 않는다. 정적 지원 문구에 이 색상을
  사용해도 disabled 접근성 상태를 붙이지 않는다. 지원 표기는 사용자가 승인한
  보조 표기로서 [Foundation의 14px 기본 기준](./foundations.md)에 대한 예외다.
- 좁은 화면에서도 전체 문구를 줄바꿈하며 말줄임하거나 접지 않는다.
- 괄호 안의 사업 번호 `(IITP-2026-AI·SW마에스트로)`는 별도 줄에서 시작한다.
- 지원 표기는 정적 텍스트이며 링크나 별도 조작을 추가하지 않는다.
