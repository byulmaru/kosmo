# 공개 콘텐츠 방문자 안내

## 권위와 범위

제품 행동은 `docs/domain/policies/public-content-onboarding.md`와 PROD-836·PROD-681을 따른다. 이 문서는 2026-10-14·2026-10-16 사용자가 선택한 안내 배치와 상호작용 표현을 기록한다. 2026-10-16 우측 가입·소개 안내 카드를 제외한 구성으로 최종 확정했다. 참고 이미지의 인증 수단과 콘텐츠 가림·조회 제한은 적용하지 않는다.

## 배치

이 안내는 Web 전용이다. Native 앱에는 비로그인 공개 화면이나 이를 위한 뒤로가기 버튼을 새로 만들지 않는다. 인증 이후 앱의 기존 navigation은 유지한다.

| Web 폭                      | 안내 surface                                                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `>= full` (1280px)          | 기존 컬럼 폭을 유지하고 하단 CTA를 표시한다. 우측 레일에는 중복 가입하기·로그인 버튼과 별도의 가입·소개 안내 카드를 표시하지 않는다. |
| `compact` 이상, `full` 미만 | 기존 80px 좌측 레일과 중앙 콘텐츠를 유지하고 하단 CTA를 표시한다.                                                                    |
| `compact` 미만 (768px)      | 하단 CTA를 표시한다. 기존 header·drawer·하단 탭 geometry를 재설계하지 않는다.                                                        |

하단 CTA는 콘텐츠와 focus된 control을 가리지 않도록 실제 높이와 safe area만큼 공간을 확보한다. 모바일 하단 탭과 겹치지 않게 배치한다. 작은 viewport나 확대 상태에서는 안내를 scroll 흐름 안에 배치할 수 있지만 내용과 action은 유지한다. 중앙 콘텐츠의 document scroll 계약과 full 레일의 기존 폭·개인정보 처리방침 링크를 유지한다. `KOSMO에서 이야기를 이어가세요` 우측 안내 카드는 표시하지 않는다.

## 안내 내용

로그인하지 않은 상태, 공개 콘텐츠를 계속 읽을 수 있다는 점, Account로 로그인하고 Profile로 글쓰기·팔로우·대화에 참여한다는 차이를 짧게 안내한다. 하단 안내는 Tumblr 모바일 웹의 하단 패널 구성을 참고하되 `KOSMO에서 계속하기` 버튼 하나를 제공한다. 지원하지 않는 전화번호·Apple·Google 버튼은 추가하지 않는다.

좌측 사이드바와 모바일 drawer의 안내 문구는 `공개 콘텐츠를 보고 있어요` / `로그인하면 프로필을 선택하거나 만들고 대화에 참여할 수 있어요.`다. 하단 CTA에는 이 설명을 반복하지 않는다. 최종 문구는 같은 의미 안에서 다듬을 수 있다. 읽기를 계속하려면 인증이 필요하다는 문구는 사용하지 않는다.

## 하단 CTA의 구성

하단은 주 버튼, 보조 링크, 닫기로 구성한다. 안내 설명은 좌측 사이드바와 모바일 drawer에만 둔다. 주 버튼의 문구는 `KOSMO에서 계속하기`로 고정하고 KOSMO 홈(`/`)을 연다. 버튼 아래에 `팀 별마루 소개`와 `개인정보처리방침`을 `·` 구분자 없이 나란히 두며, 좁은 폭이나 큰 글자에서는 줄바꿈을 허용한다. `팀 별마루 소개`는 `https://byulmaru.co/about-us`, `개인정보처리방침`은 `/privacy`를 연다. 보조 링크는 주 버튼과 구분되는 text link로 표시하되 각각 keyboard focus와 독립된 입력 영역을 제공한다.

닫기는 주 버튼과 겹치지 않는 독립된 입력 영역에 배치하며 패널 전체를 숨긴다. 두 보조 링크를 가리거나 주 버튼의 클릭 영역에 합치지 않는다. Tumblr에서 관찰한 닫기 없는 바를 그대로 채택하지 않고 기존 탭 단위 닫힘 합의를 유지한다.

## 좌측 안내와 상태

비로그인 공개 화면은 보호 navigation과 계정 action 대신 계정 안내와 별도의 `가입하기`·`로그인` 버튼을 표시한다. 기존 인증 사용자와 선택 Profile이 없는 인증 사용자의 메뉴·ProfileSwitcher는 유지한다. full 사이드바와 mobile drawer에는 두 버튼의 label을 표시한다. compact rail에도 두 action을 구분해 제공하고 accessible name은 각각 `가입하기`와 `로그인`으로 유지한다. drawer에서도 같은 상태와 목적지를 전달한다. `가입하기`는 `https://kos.moe/`의 홈(`/`)을 열고 `로그인`은 `/login`을 연다.

## 모바일 사이드바 접근

비로그인 mobile Web의 공개 Profile·Post 헤더는 왼쪽 햄버거 모양의 `메뉴 열기` 버튼과 제목을 사용한다. 별도의 뒤로가기나 오른쪽 메뉴 버튼은 추가하지 않는다. CTA를 닫아도 이 버튼은 남으며, pointer·touch·keyboard로 같은 좌측 drawer를 연다. 별도의 header 행이나 헤더 로그인 버튼은 추가하지 않는다. drawer의 focus 이동·닫기·trigger 복귀는 기존 공용 동작을 사용한다.

## 닫기와 접근성

하단 CTA의 닫기에는 `가입 안내 닫기` accessible name을 제공한다. 현재 탭에서 공개 route 사이를 이동해도 닫힘을 유지하고 다른 탭의 상태와 공유하지 않는다. 안내가 사라져도 좌측 가입·로그인 진입은 유지한다.

비모달 안내이므로 자동 focus 이동이나 focus trap을 사용하지 않는다. keyboard로 모든 CTA와 닫기에 도달할 수 있고 focus-visible, 대비, zoom·reflow와 pointer target은 `accessibility.md`를 따른다. loading·조회 오류는 guest로 표시하지 않는다. 유효 Session이 확인되면 guest 안내를 제거한다.
