## ADDED Requirements

### Requirement: 상단 현재 타임라인 탭을 다시 선택하면 스크롤만 수행한다

**Source Context:** [PROD-1162](https://linear.app/byulmaru/issue/PROD-1162), 2026-10-22 사용자의 “새로고침 말고 맨 위로 스크롤만 해”, `docs/design/local-timeline.md`. Web·iOS·Android는 상단에서 현재 선택된 홈 또는 로컬 탭을 다시 활성화하면 현재 타임라인 맨 위로 이동해야 한다(SHALL). 이 입력은 현재 탭과 route를 유지해야 하며(MUST), 추가 navigation이나 데이터 재조회를 시작해서는 안 된다(MUST NOT). 비활성 탭 전환과 별도 새로고침 진입점의 기존 동작을 유지해야 한다(MUST).

#### Scenario: 선택된 홈 탭을 다시 활성화한다

- **WHEN** 홈 타임라인을 아래로 스크롤한 상태에서 상단 홈 탭을 다시 활성화한다
- **THEN** 현재 홈 타임라인 맨 위로 이동한다
- **AND** 홈 선택과 route가 유지되고 이 입력으로 타임라인 데이터 재조회가 시작되지 않는다

#### Scenario: 선택된 로컬 탭을 다시 활성화한다

- **WHEN** 로컬 타임라인을 아래로 스크롤한 상태에서 상단 로컬 탭을 다시 활성화한다
- **THEN** 현재 로컬 타임라인 맨 위로 이동한다
- **AND** 로컬 선택과 route가 유지되고 이 입력으로 타임라인 새로고침이 시작되지 않는다

#### Scenario: 연속 입력 또는 별도 새로고침 진행 중에 다시 활성화한다

- **WHEN** 현재 상단 탭을 연속으로 활성화하거나 다른 경로의 새로고침 진행 중에 다시 활성화한다
- **THEN** 각 활성화는 현재 타임라인 맨 위 이동만 수행한다
- **AND** 추가 navigation이나 데이터 재조회를 시작하지 않으며 이미 진행 중인 별도 새로고침의 기존 완료·실패 동작을 유지한다

#### Scenario: 비활성 타임라인 탭으로 전환한다

- **WHEN** 현재 홈에서 로컬을 선택하거나 현재 로컬에서 홈을 선택한다
- **THEN** 기존 플랫폼별 탭 전환과 해당 타임라인의 진입·데이터 갱신 동작을 따른다
- **AND** 이번 재선택 동작을 이유로 별도 새로고침을 추가하지 않는다

#### Scenario: 키보드 또는 보조 기술로 현재 탭을 활성화한다

- **WHEN** 기존 키보드 또는 보조 기술 활성화 경로로 현재 상단 탭을 실행한다
- **THEN** 포인터·터치와 같은 맨 위 이동만 수행한다
- **AND** 기존 탭 선택·focus 표현과 이동을 유지한다

#### Scenario: 별도 새로고침 진입점을 실행한다

- **WHEN** 하단 내비게이션·Web 홈 진입점을 재선택하거나 Native pull-to-refresh를 실행한다
- **THEN** PROD-1079·PROD-610·PROD-1005의 기존 스크롤·새로고침 동작을 따른다
- **AND** 상단 탭의 스크롤 전용 동작으로 이 새로고침을 대체하지 않는다
