## Current Approach

공개 Profile·Post route의 Web guest에게 기존 셸에서 사이드바·drawer 가입·로그인과 닫을 수 있는 하단 CTA를 제공한다. 가입·하단 CTA는 `/`, 로그인은 `/login`을 사용한다. 안내의 닫힘만 현재 탭에 저장한다. 기존 인증 callback과 Profile 준비 경로를 유지한다.

## Scope

2026-10-19 사용자 지시와 PR #1191 리뷰에 따라 복귀 대상 전달·저장·이동과 그 전용 검증을 제거했다. 자동 복귀의 필요성은 Linear에서 재논의하며 별도 구현을 확정하지 않았다. 이 파일은 현재 세션 메모이며 추가 제품 계약이 아니다.
