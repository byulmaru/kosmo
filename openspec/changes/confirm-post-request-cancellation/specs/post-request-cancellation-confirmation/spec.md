## ADDED Requirements

**Source Context:** [PROD-1287](https://linear.app/byulmaru/issue/PROD-1287)의 완료 조건. 파일 업로드 뒤 게시를 요청하고 HOPE 보호 처리를 기다리는 기존 카드에 적용한다. 이 문서는 해당 요구를 검증할 세션 메모다.

### Requirement: 보호 처리 대기 중 게시 요청 취소 확인

사용자가 대기 카드의 `취소`를 누르면 시스템은 확인 알림을 먼저 표시하고, 사용자가 취소를 확정한 경우에만 기존 게시 요청 취소 동작을 실행해야 한다(SHALL).

#### Scenario: 취소 확인 알림 열기

- **WHEN** HOPE 보호 처리를 기다리는 취소 가능한 요청 카드에서 `취소`를 누른다
- **THEN** 취소 여부를 묻는 확인 알림을 표시한다
- **AND** 확인 알림을 여는 것만으로 게시 요청을 취소하지 않는다

#### Scenario: 취소 확정

- **WHEN** 사용자가 확인 알림에서 게시 요청 취소를 확정한다
- **THEN** 해당 요청에 기존 취소 동작을 실행한다
- **AND** 기존 서버 결과에 따라 요청 상태를 반영한다

#### Scenario: 취소하지 않고 대기 유지

- **WHEN** 사용자가 확인 알림에서 취소하지 않기로 한다
- **THEN** 확인 알림을 닫고 게시 요청을 유지한다
- **AND** 기존 처리 상태 조회를 계속한다

#### Scenario: 확인 알림 닫기

- **WHEN** 사용자가 확정하지 않고 공용 닫기 경로로 알림을 닫는다
- **THEN** 게시 요청 취소 동작을 실행하지 않는다
- **AND** 기존 게시 요청을 유지하고 계속 대기한다
