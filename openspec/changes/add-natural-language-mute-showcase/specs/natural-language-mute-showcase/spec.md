이 문서는 현재 사용자 확인과 PROD-1160의 결과를 제작 중 다시 확인하기 위한 예시다. 실제 서비스의 뮤트 계약이나 모델 동작을 추가하지 않는다.

## ADDED Requirements

### Requirement: 문장 입력 예시와 피드 가림 결과를 이어서 소개한다

**Source Context**: [PROD-1160](https://linear.app/byulmaru/issue/PROD-1160)의 포함 범위·완료 기준과 2026-10-19 사용자 확인.

소개 자료는 HTML 목업 또는 이미지에서 자연어 문장 입력 예시와 그 조건에 따른 예시 피드 가림 결과를 이어서 보여주어야 한다(SHALL). 입력·적용 기능을 실제로 실행할 필요는 없다.

#### Scenario: 준비한 화면으로 흐름을 소개한다

- **WHEN** 행사에서 준비한 소개 자료를 보여준다
- **THEN** 방문자는 무엇을 입력하는지와 어떤 예시 글이 가려지는지 확인할 수 있다
- **AND** 실제 타이핑이나 모델 호출 없이도 화면의 순서와 관계를 이해할 수 있다

### Requirement: 내부 모델 지식 없이 기능을 이해할 수 있다

**Source Context**: [PROD-1160](https://linear.app/byulmaru/issue/PROD-1160)의 내부 모델 이름을 몰라도 기능과 사용 방법을 이해할 수 있는 안내.

소개 자료는 방문자가 내부 모델 이름을 몰라도 문장으로 보고 싶지 않은 내용을 설정하는 구상을 이해할 수 있게 안내해야 한다(SHALL).

#### Scenario: 방문자가 안내와 예시를 읽는다

- **WHEN** 방문자가 소개 자료의 한국어 안내와 예문을 읽는다
- **THEN** 내부 모델 이름이나 학습·추론 구조를 알아야만 기능을 이해하는 설명에 의존하지 않는다

### Requirement: 모의 자료로 소개하며 실제 연동을 요구하지 않는다

**Source Context**: [PROD-1160](https://linear.app/byulmaru/issue/PROD-1160)의 시연용 데이터·모의 결과 허용과 제외 범위.

소개 자료는 시연용 데이터와 모의 결과로 구상을 설명할 수 있어야 한다(SHALL). 실제 Jev/Decision model, 백엔드와 운영 데이터 연동 또는 프로덕션 뮤트 정책 변경은 요구하지 않는다.

#### Scenario: 실제 모델과 백엔드 없이 소개한다

- **WHEN** 실제 모델과 백엔드를 연결하지 않은 자료를 보여준다
- **THEN** 준비한 예시로 문장과 피드 가림 결과의 관계를 설명할 수 있다
- **AND** 모의 결과를 모델의 성능 검증이나 실제 서비스 정책 변경의 증거로 제시하지 않는다
