# `/opsx:explore [topic]`

Explore through the shared [OpenSpec explore guidance](../../../.codex/skills/openspec-explore/SKILL.md).

The optional `topic` argument is the complete exploration target: it may be a vague idea, concrete problem, change name, comparison, or empty. Keep this command read-only for application code, tests, and configuration. If the user explicitly asks to build, continue through the shared proposal or apply handoff and reuse an existing approved change when available.
